# StreetCleaning

StreetCleaning je webová aplikácia vytvorená v ASP.NET Core MVC, ktorá umožňuje vyhľadávať informácie o plánovaných upratovaniach ulíc.

## Funkcionalita

- vyhľadávanie plánovaných upratovaní podľa obce a ulice,
- zobrazenie plánovaných termínov upratovania,
- zobrazenie zrušených upratovaní,
- zobrazenie realizovaných upratovaní,
- filtrovanie podľa časového obdobia.

## Technológie

- ASP.NET Core MVC
- Entity Framework Core
- Oracle Database
- Bootstrap 5
- Serilog
- xUnit
